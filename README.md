# PCPartz - Платформа для продажи компьютерных деталей

## Описание проекта
Онлайн-платформа для быстрой покупки и продажи комплектующих для компьютеров. Было сделано в рамках лабораторной работы для университета.

## Основные функции
- 🖥️ **Каталог деталей** (процессоры, видеокарты, ОЗУ и др.)
- 🔍 **Умный поиск** с фильтрами по параметрам
- 🛒 **Корзина покупок** и избранное
- 💬 **Система отзывов** и рейтингов продавцов
- 📱 **Адаптивный дизайн** для мобильных устройств

## Технологический стек
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Django 4.2, Python 3.10
- **База данных**: SQLite
